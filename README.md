# vibe-coding-touch-typing-tutor
Пример проекта для курса Otus. Vibecoding. Тренажер слепой печати.

# Основная задача

Разработать WEB приложение - Тренажер для слепой печати

# Основные части

1. Регистрация и авторизация для разных пользователей
2. Сохранение прогресса пользователя
3. Сам тренажер - основная фича

# Работа тренажера

В папке alphabet находиться файл main.txt находятся символы алфавита для изучения (может быть любой язык)

Мы будем изучать алфавит начиная с первых букв к последним, например
первая буква j (правая рука, средний ряд), последняя 0 (циферный ряд)

Тренажер будет создавать уровни для изучения пользователем и добавлять на каждому уровне по букве. Например:

1 уровень: j
2 уровень: jf
3 уровень: jfk
...
последний уровень: весь алфавит. 

Пользователь может переключить уровни по своему желанию с первого по последний и обратно. 

Само задание на уровне будет состоять из случайных символов (доступных на уровне) разделенных перобелом, случайной длины. Всего максимум 50 символов (должно менять динамически из настроек)

Например:
1 уровень: j j j j j j j j j j 
2 уровень: j jfj ff jjf j jfjf 
...

В одном окне будет задание (что напечатать)
В другом окне пользователь будет пробовать напечатать то что написано.
Система будет сравнивать что набирает пользователь и если он ввел неправильно - сигнализировать об ошибке и сбрасывать весь прогресс и предлагать ввести снова

# Систем и интерфейс

Приложение должно работать в WEB интерфейсе с сохранением прогресса пользователя.

Страницы:
- Сам тренажер (не доступен без авторизации)
- Регистрация 
- Авторизация
- Кнопка выход
- Главная страница с кратким описанием работы тренажера

# Дизайн

- Современный, привлекательный, минималистичный

# Дополнительные функции

1. Регистрация (email + password)
2. Авторизация (email + password)
3. Сохранение прогресса (пользователь начинает работу с уровня который у него сохранился)
